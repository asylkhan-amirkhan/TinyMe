# Мой рост — первый этап TinyMe

В комнате открой **«Мой рост»** в основном меню.

1. Создай навык с названием, цветом и категорией занятия. Можно выбрать один из четырёх необязательных примеров.
2. При желании создай цель внутри навыка.
3. Добавь отдельную задачу или шаг цели. Задача цели наследует её навык.
4. Выбери сложность: простая — 10 XP, средняя — 25 XP, сложная — 50 XP.
5. Выполни действие в реальной жизни и подтверди результат. Только сохранённое выполнение начисляет XP.

## Что входит

- Свои навыки и цели, задачи и история последних результатов.
- Отдельный XP каждого навыка. Порог уровня L: `50 × L × (L − 1)`.
- Первые шаги до уровня 3, уверенная практика с уровня 3, мастерство с уровня 9.
- Архивация и восстановление навыка без потери истории; новые действия архивного навыка недоступны.
- Подтверждение перед завершением, защита от повторного XP, видимый следующий порог.
- Отклик жителя через существующее занятие категории; при отсутствии нужной мебели — прогулка. Пауза, скрытый житель и отключённая анимация сохраняются.
- Монеты комнаты и XP навыков учитываются независимо. Перерывы не уменьшают опыт.

Это первый этап основного сценария ТЗ 1.4. **Отдельные анимации мастерства, выдача наградных предметов, граф, альбом, экспорт/импорт и друзья в этот этап не входят.** Новая система пока использует существующий гостевой режим; обязательная авторизация и SSR-сессии из ТЗ — отдельная работа.

## Сохранение

Гостевые данные записываются в `tinyme:growth:guest:v1` в localStorage. Web Locks сериализует операции между вкладками. При ошибке записи успех не показывается; повреждённое или неизвестное сохранение не заменяется пустым.

Данные аккаунта обслуживает RPC `tinyme_growth`. Ошибка облака не переключает пользователя на гостевой профиль. Переноса гостевого прогресса в аккаунт пока нет.

### Подготовленный облачный backend

[supabase/growth.sql](../supabase/growth.sql) содержит отдельную таблицу и транзакционную RPC. Установка требует отдельного применения к выбранному проекту Supabase. **В рамках этой поставки SQL не применён и выполнение SQL-тестов не подтверждено.**

Таблица закрыта от прямого чтения и записи клиентскими ролями, RLS включён. RPC с `SECURITY DEFINER` проверяет подтверждённого владельца и действующую серверную сессию, не принимает произвольный XP и блокирует строку профиля на время команды. Повтор завершения задачи возвращает прежний результат без новых событий. Скрипт добавляет собственные объекты и не изменяет комнату, кошелёк и музыку.

После одобренной установки выполнить [tests/growth.sql](../tests/growth.sql): транзакционные проверки создают изолированные фикстуры и заканчиваются `ROLLBACK`. Требуется также проверить параллельное завершение с двух устройств и реальный вход через браузер. Пока RPC не установлен, раздел аккаунта показывает сообщение о недоступном облачном прогрессе.

## Проверки

```sh
npm run typecheck
npm test
```

`tests/growth.test.ts` проверяет награды 10/25/50 XP, границы уровней, повторное завершение, наследование навыка цели, архив, повреждённые данные и отказ записи. SQL-сценарий запускается отдельно и не входит в `npm test`.
